How are memories stored and retrieved?

Open question

We know that connections between neurons change when we learn. We cannot read a memory in a brain.

What we know

  • Memories are associated with groups of neurons, called engrams, which activate when we remember.
  • In mice, an engram has been artificially activated and a recall behaviour triggered.
  • The hippocampus plays a central role in forming recent memories.

What we don't know

  • Where and how long-term memories are stored.
  • Why some memories are kept and others lost.

Why it's hard

  • A memory cannot be observed: we see only neuronal activity, which leaves room for different interpretations.
  • Most precise experiments are done in mice, not in humans.

Why it matters

Understanding memory sheds light on diseases such as Alzheimer's and on how we learn.

Going further

Memory is the faculty of the mind by which data or information is encoded, stored, and retrieved when needed. It is the retention of information over time for the purpose of influencing future action. If past events could not be remembered, it would be impossible for language, relationships, or personal identity to develop. Memory loss is usually described as forgetfulness or a disorder such as amnesia.
